## Goal

Profiles are loud — read the contract before you hit publish

## Architecture (summary)

Open **[handout.pdf](./handout.pdf)** for the full tables.

| Surface | Volume | Today's default |
| --- | --- | --- |
| GitHub + case study (Days 94–95) | Quiet proof | Already public if you sanitized |
| LinkedIn learning posts | Classroom volume | This series — educational, no hire-me CTA |
| Paid-work marketplace profile | Loud — implies you are for hire | Draft offline; activate only if policy allows |
| Personal site contact form | Medium | Optional; still not a sales page in this series |
| Work laptop / work tenant | Forbidden volume | Personal equipment, personal time, personal Azure |

## Step-by-step lab

1. Read your employer moonlighting and IP policy (if you have an employer). If you are independent, write that fact in the notes. Do this before any paid profile.
2. Create docs/profile-draft-day98.md offline: headline, three bullets tied to the public capstone, links to GitHub and the case study.
3. Checklist in that file: policy reviewed, portfolio links ready, personal equipment only, no customer targeting.
4. Do not activate a paid marketplace profile today unless the policy clearly allows it. A local draft is the lab.
5. If policy says no, the draft stays a draft. GitHub and the case study remain the quiet proof.
6. Do not use a work laptop, work tenant, or work time. Do not target any employer's customers.

## Done when

- [ ] Policy read (or independent noted) before any paid profile
- [ ] Offline draft exists with portfolio links
- [ ] No work laptop, no customer targeting
- [ ] Paid profile still off unless clearly allowed
- [ ] This post has no hire-me CTA
