## Step-by-step lab

1. Open the official AZ-400 skills outline on Microsoft Learn (exams/az-400). Save the link in docs/az400-gaps-day96.md.
2. Tick each objective: practiced in these 100 days / skimmed / never. Honesty is the lab.
3. Write a weekend study list of the never/skimmed rows only — a few bullets, not the whole outline.
4. For three practiced rows, write the lab artifact that proves it (pipeline file, Insights alert, infra plan).
5. Do not write AZ-400 certified on a profile. Do not invent a score. Do not cram the whole outline tonight.
6. Optional: add the outline PDF or a screenshot of the contents table — not a brain-dump site.
